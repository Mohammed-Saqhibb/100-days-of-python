## Learning Focus: Functions and While Loops

### Functions
Functions allow us to:
- Write reusable code blocks
- Avoid repetition (DRY principle)
- Organize code logically
- Make debugging easier

### While Loops
While loops are useful for:
- Repeating code until a condition is false
- Input validation
- Game loops
- Processing undefined iterations
