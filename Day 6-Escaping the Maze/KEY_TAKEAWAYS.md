## Day 6 - Key Takeaways

### What is a Function?
A function is a reusable block of code that performs a specific task.

**Benefits:**
- Code reusability
- Improved readability  
- Easier maintenance
- Modular design
- Easier testing

### Function Structure
```
def function_name(parameters):
    """Docstring explaining what function does"""
    # Function implementation
    return result
```

### While Loop Structure
```
while condition:
    # Code that executes repeatedly
    # Must eventually make condition False
```

### When to Use Functions
- When code is repeated more than once
- When code performs a single task
- When you want to make code testable
- When you want to improve code organization

### When to Use While Loops
- When you don't know how many iterations needed
- For input validation
- For game loops
- For processes that continue until a condition

### Common Errors to Avoid
1. **Infinite loops** - Always ensure loop terminates
2. **Uninitialized variables** - Initialize before loops
3. **Function side effects** - Functions should be pure
4. **Scope issues** - Understand local vs global
5. **No return statement** - Function returns None implicitly
