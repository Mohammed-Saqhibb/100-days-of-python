### Troubleshooting Common Issues

**Issue:** "NameError: name 'X' is not defined"
- Check variable scope (local vs global)
- Ensure variable initialized before use

**Issue:** "IndentationError"
- Check consistent spacing in function/loop blocks
- Use 4 spaces per indent level

**Issue:** Program runs but doesn't produce output
- Add print statements
- Check loop conditions
- Verify function returns values
